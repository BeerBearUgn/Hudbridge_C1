# HUD Bridge

Навигация с телефона на автомобильный проекционный дисплей **C1 (WiiYii)** — с Яндекс Навигатором и без замены штатного режима OBD.

---

## Зачем это

HUD C1 подключается к OBD-разъёму и сам по себе показывает скорость, обороты, напряжение и температуру. Навигация у него заявлена, но работает только через фирменное приложение WiiYii, которое умеет вести маршрут лишь по Google Maps и китайским офлайн-картам. В России это бесполезно: адреса ищутся плохо, интерфейс наполовину на китайском, а Яндекс Навигатор — основной маршрутизатор — не поддерживается вовсе.

Цель проекта: **подсказки Яндекс Навигатора выводятся на HUD, а скорость и температура остаются на месте.** Стрелка манёвра и расстояние до него появляются только на подъезде к повороту, всё остальное время дисплей работает как обычно. Телефон при этом может быть подключён к Android Auto — картинка идёт на экран машины, стрелки на HUD.

Экран у C1 сегментный, поэтому карту на него не вывести физически. Речь именно о стрелках, дистанции и предупреждениях.

## Как это устроено

```
Яндекс Навигатор  ──уведомление──▶  HUD Bridge  ──Bluetooth LE──▶  HUD C1
(манёвр, дистанция)                 (телефон)                      (стрелка + метры)
                                                    OBD-II ────────▶ скорость, температура
```

Приложение не перехватывает экран Android Auto — это невозможно. Оно читает системное уведомление навигатора, в котором уже лежат следующий манёвр и расстояние до него, и отправляет их на HUD его же родными командами.

## Статус: этап 1 — диагностика

Протокол HUD закрыт, формат уведомлений Яндекса не документирован. Поэтому первая версия приложения ничего не отправляет, а собирает данные для реверс-инжиниринга.

| Инструмент | Что делает |
|---|---|
| Чтение уведомлений | Сохраняет всё содержимое уведомлений Яндекс Навигатора, Яндекс Карт и Google Maps: тексты, скрытые поля, данные Samsung Now Bar и картинки стрелок |
| BLE-исследователь | Находит HUD, выгружает его сервисы и характеристики, записывает входящие пакеты, отправляет произвольные HEX-команды |
| Экспорт | Складывает логи и картинки в «Загрузки/HudBridge/<дата>» |

Логи — построчный JSON, иконки — PNG рядом.

## Сборка

**GitHub Actions.** Вкладка Actions → workflow `build-apk` → артефакт `HudBridge-debug-apk`.

**Android Studio.** File → Open → папка проекта → Build → Build APK(s). Если Studio предложит создать Gradle wrapper, соглашайтесь.

Требования: JDK 17, Android SDK 35, minSdk 29.

## Порядок сбора данных

### 1. Уведомления Яндекса
1. В приложении: «Выдать доступ к уведомлениям» → включить HUD Bridge.
2. Проложить маршрут в Яндекс Навигаторе, свернуть его и проехать 3–4 разных манёвра: направо, налево, разворот, кольцо.
3. Повторить с телефоном, подключённым к Android Auto.
4. «Экспорт в Загрузки».

### 2. Структура HUD
1. Закрыть официальное приложение WiiYii, иначе оно займёт соединение.
2. «Сканировать BLE» → выбрать HUD (имя вида HUD / C1 / WiiYii).
3. Подождать 30 секунд: в лог попадут сервисы, характеристики и то, что HUD шлёт сам.
4. «Экспорт в Загрузки».

### 3. Протокол навигации — главный шаг
Нужно записать, что фирменное приложение отправляет в HUD во время ведения по маршруту.

1. Включить параметры разработчика: Настройки → Сведения о телефоне → Сведения о ПО → семь раз нажать «Номер сборки».
2. Параметры разработчика → «Журнал отслеживания Bluetooth HCI» → выключить и снова включить Bluetooth.
3. Запустить навигацию на HUD любым работающим способом: официальный WiiYii с Google или стороннее приложение `com.avashield.wiiyiihudnavigator` вместе с Google Maps.
4. Проехать несколько поворотов, сняв HUD на видео — по времени на записи пакеты сопоставляются со стрелками.
5. Забрать лог: Параметры разработчика → «Отчёт об ошибке» → «Интерактивный». Внутри архива нужен `FS/data/log/bt/btsnoop_hci.log`. Запасной путь для Samsung: набрать `*#9900#` → Run dumpstate/logcat → Copy to sdcard.
6. Выключить журнал HCI.

## Что дальше

**Этап 2 — передача манёвров.** Фоновый сервис: читает манёвр и дистанцию из уведомления, держит соединение с HUD, отправляет стрелку только когда до поворота меньше заданного порога, в остальное время молчит. Автоподключение при посадке в машину.

**Этап 3 — по результатам.** Предупреждения о камерах и превышении, дублирование «перестройтесь в полосу», настройка порога и яркости.

Откроется ли стрелка одновременно со скоростью или HUD переключит экран целиком — покажет эксперимент 3.

## Структура проекта

```
app/src/main/java/tech/gratio/hudbridge/
├── MainActivity.kt        экран: кнопки, список устройств, живой лог
├── NavListenerService.kt  слушатель уведомлений навигаторов
├── NotifParser.kt         разбор уведомления, включая кастомные RemoteViews и иконки
├── BleExplorer.kt         скан, GATT-дамп, подписки, отправка HEX
└── LogStore.kt            журнал JSON Lines, сохранение картинок, экспорт
```

## Приватность

Всё остаётся на телефоне: приложение пишет логи в память устройства и никуда их не отправляет. Интернет ему не нужен, разрешения на сеть в манифесте нет. Логи уведомлений могут содержать адреса из маршрутов — смотрите, что отправляете.
